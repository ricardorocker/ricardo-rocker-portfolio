## The Portfolio

Built with Next.js 16.3.5 + React 19 + Tailwind v4 + Motion 13.

### Pages

| Route | Description |
|-------|-------------|
| `/` | Hero, services bento, stats, FAQ, CTA |
| `/about` | Full bio, experience timeline, expertise areas |
| `/case-studies` | 3 demonstration projects (fictional) |
| `/stack` | Full skill breakdown with experience levels |
| `/showcase` | 6-project visual grid |
| `/contact` | Contact form + direct links |
| `/og` | Dynamic OG image generation |
| `/sitemap.xml` | SEO sitemap |
| `/robots.txt` | Crawler configuration |

### Tech Decisions

- **Tailwind v4** with CSS custom properties for theming (light/dark mode)
- **Motion 13** for scroll-triggered animations and micro-interactions
- **Geist font** from Vercel for consistent typography
- **Lenis** for buttery smooth scroll
- **Static-first** — all pages pre-rendered except OG image route
- **Zero runtime errors** — TypeScript strict mode enforced
